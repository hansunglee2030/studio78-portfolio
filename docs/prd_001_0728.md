## 1. 개요 (Executive Summary)

스튜디오78(대표 이한성)의 프리랜서 활동을 소개하는 **단일 파일 정적 포트폴리오 웹페이지**. 방송 프로그램 제작과 AI 영상 제작 역량을 알리고, 대표 선정작 **미식실록**을 전면에 내세워 방송사·글로벌 OTT·공동제작 파트너의 문의를 유도한다.

- **형태**: `index.html` 단일 파일 (빌드 불필요, Vercel 정적 배포)
- **핵심 목표**: 신뢰 전달 + 문의 전환(이메일·인스타그램)

## 2. 배경 & 목표 (Goals)

| 구분 | 내용 |
|------|------|
| 배경 | KCA 2026 해외진출형 방송콘텐츠 기획개발 지원사업에 '미식실록'이 선정되어, 이를 부각한 소개 페이지 필요 |
| 목표 1 | 대표 선정작을 첫 화면 직후 스포트라이트로 노출 |
| 목표 2 | SNS 공유·검색 노출 강화 (OG/트위터 카드, JSON-LD) |
| 목표 3 | 접근성·다크모드 등 완성도 높은 사용자 경험 제공 |
| 성공 지표 | 이메일/인스타 문의 발생, SNS 공유 시 카드 정상 노출 |

## 3. 타깃 (Target Audience)

- 방송사·제작사 편성/기획 담당자

## 7. 비기능 요구사항 (Non-Functional)

- **SEO**: title/description, Open Graph, Twitter Card, canonical, JSON-LD(ProfessionalService), favicon(인라인 SVG)
- **접근성(a11y)**: 본문 바로가기, `:focus-visible`, 장식 요소 `aria-hidden`, 링크 `aria-label`, 모션 최소화 존중
- **성능**: 외부 의존성 0(폰트·JS 라이브러리 없음), 단일 파일
- **호환**: 최신 브라우저 + JS 비활성 시에도 콘텐츠 노출(리빌 폴백)

## 8. 콘텐츠 원칙 (Content Policy)

> **사실 무결성 원칙**: 실제 인물의 포트폴리오이므로 미확정 정보를 단정적으로 표기하지 않는다.
- 미식실록의 **섭외 캐스팅(특정 인물)과 예산 수치**는 제안 단계 → 공개 페이지 미표기 (요청 시 표기)
- 방송사·작업 사례는 실제 이력만 기재, 임의 추가 금지
- 진행 방식 등 일반 서술은 사실 왜곡 없는 범위로 한정
